# v1.0 — first release

### الكابتن ماجد ٤ بالعربية

The full game in Arabic, in a tall 8×16 font with joined letters, read right to
left from the first screen to the last.

## What's in it

- **Script.** All 4,800+ lines of story, match and menu text, checked against
  the Japanese and fitted to the boxes they appear in.
- **Names.** 510 players, 85 teams and 165 special moves, using the names from
  the Arabic dub of الكابتن ماجد. Players with long names have a short form
  for the narrow boxes.
- **Screens mirrored.** Menus, the stats pages, the pass target screen, the
  team select and the settings screen are laid out right to left, cursors
  included.
- **Commentary.** Rewritten in the style of رؤوف خليف, including the idle
  chatter while the game waits for a button. Calls read naturally:
  «ماجد ينفذ …» for a special move, «يسجل عن طريق تسديدة» for a plain shot,
  يووزع for a player and يمرر for a goalkeeper.
- **Arabic voice-over.** The pre-match shout is now
  «مستعدون؟ مستعدون! هيا لنخرج الآن هيا!», with the text box to match.
- **New opening.** Each star is introduced with his nickname before
  «في مواجهة الأقوى... / والآن... لا تراجع! / مباريات حارقة تنتظر!».

## Known issues

- Savestates made with an older test build keep the old sound driver, so the
  pre-match voice may play in Japanese until you start from power-on or an
  in-game save.
